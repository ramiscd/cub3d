# libft

Copy your libft sources and its `Makefile` into this folder.

Requirements for this project:

- `make` inside this folder must produce `libft.a` here.
- `libft.h` must be at the root of this folder (it is included as `"libft.h"`).
- `get_next_line` must be available (used to read the `.cub` file).

Delete this README after copying the libft.
